\chapter*{Kivonat}\addcontentsline{toc}{chapter}{Kivonat}

A szakterület-specifikus nyelvek (\glslink{DSL}{DSL}) az informatika számos részén jól használható és kényelmes lehetőséget nyújtanak egy-egy speciális feladatkör megoldására.
Manapság számos olyan eszköz elérhető, amely \glslink{DSL}{DSL}-ek fejlesztésére alkalmas, de kevés olyan programnyelv létezik, amelybe a \glslink{DSL}{DSL}-ek kényelmesen beágyazhatók.

A dolgozatban egy általam kifejlesztett általános célú programnyelvet mutatok be, amelyben -- a nyelv kialakításának köszönhetően -- könnyedén lehet \glslink{DSL}{DSL}-eket definiálni és futtatni.
A nyelv fordítója LLVM technológiára épít, így akár \glslink{JIT}{JIT} segítségével, akár teljes natív fordítással lehetővé teszi a megvalósított \glslink{DSL}{DSL}-ben írt programok futtatását.

A dolgozatban demó jelleggel bemutatok néhány gyakorlatban is használható \glslink{DSL}{DSL}-t, valamint egy nagyobb léptékű jövőbeli bővítési tervet.

\chapter*{Abstract}\addcontentsline{toc}{chapter}{Abstract}

Domain-specific languages (\glslink{DSL}{DSL}s) are useful in numerous fields of computer science and provide a convenient way to solve a specific set of tasks.
Today there are many tools available for developing \glslink{DSL}{DSL}s, but few programming languages exist into which \glslink{DSL}{DSL}s can be easily embedded.

In this paper, I present a general-purpose programming language that I developed, in which \glslink{DSL}{DSL}s can be easily defined and executed thanks to the way the language is designed.
The language's compiler is based on LLVM technology, so it allows programs written in the implemented \glslink{DSL}{DSL} to be executed either with \glslink{JIT}{JIT} or with full native compilation.

As a demonstration, I present a few \glslink{DSL}{DSL}s that can be used in practice, as well as a larger-scale plan for future expansion.
